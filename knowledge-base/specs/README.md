# specs/

In-vault pointers to the canonical specifications in `docs/`. Each note is a graph node that links
**out** to the real document (relative markdown link), so the specs appear in the vault without
copying their contents.

- [[AmbiSQL Static Interface]] — the C2 spec.
- [[Dynamic Interface]] — the C3 spec (primitives, `{jsx, fields}`, sandbox).
- [[Model Prompts]] — call 1 / call 2 prompt wording + contracts.
- [[Page Copy]] — neutral participant-facing copy.
- [[Build Brief]] — the canonical build brief (the source of truth; §-referenced everywhere).
